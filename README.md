The winning front page for **Friday 20 November 2026**: 38 stories across seven
regions — the missile barrage on Kyiv, Cyclone Akvan at Gopalpur, the Asian AI
sell-off, the UK–EU reset, COP31's overtime in Antalya, the Peru quake, Hormuz
tankers and the FBI database breach. `entry.png` is a 1024 × 1024 PNG, 996,525 bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` validates the committed PNG (signature, size, IEND chunk) and copies its
exact bytes to the output directory. `art2.py` redraws the image from hand-authored
geometry and text — no network, no downloads — so two runs write identical bytes.
